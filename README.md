# Real Estate Website

This project contains a React + Vite front-end for a real estate landing page.

## Prerequisites

- Node.js 18+ (recommended)
- npm

## Run locally

From the repository root:

```bash
cd client
npm install
npm run dev
```

Then open the URL shown in terminal (usually `http://localhost:5173`).

## Build for production

```bash
cd client
npm run build
```

The build output is generated in:

- `client/dist`

## Preview production build

```bash
cd client
npm run preview
```
